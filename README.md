# Tombstone City: 21st Century

Tombstone City: an old ghost town now populated by a slowly deteriorating cemetery, tumbleweeds - and vicious alien morgs. The morgs threaten to overrun the town, but you're not going to let that happen, are you? In this multi-direectional shooter, destroy the morgs and the tumbleweeds they feed on, while making sure they don't feed on you. Make the town habitable again in this loving remake of [the 1981 classic](https://en.wikipedia.org/wiki/Tombstone_City:_21st_Century) developed for the Texas Instruments TI-99/4A home computer.

Tombstone City: 21st Century is written in Golang using the [Oak game engine](https://github.com/oakmound/oak) and the [Oto sound library](https://github.com/ebitengine/oto).

Releases available for Windows (amd64) and macOS (arm64), but builds on any [Golang](https://go.dev)-supported platform.
